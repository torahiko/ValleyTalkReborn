
Color values can be a color name (Red), RGB code (255 0 0), or hex code (#FF0000).

This site may be useful for finding colors:
https://rgbcolorcode.com/

Many colors will require the RGB or hex code, because the game doesn't recognize their name as a valid color. A list of supported color names can be found here:
https://www.w3schools.com/colors/colors_groups.asp
